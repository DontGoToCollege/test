# test

An app for iPhone, iPad and Mac, made on Windows with [Orchard](https://github.com/DontGoToCollege/Orchard).

## Download

Get the newest build from the [Releases page](../../releases/latest).

- **Mac:** download the file ending in `macOS.zip` and unzip it. The first time you open the app, macOS blocks it because it has no Apple signature: open System Settings, go to Privacy & Security and click **Open Anyway**.
- **iPhone and iPad:** the file ending in `iOS.ipa` has no Apple signature. Install it with a sideloading tool such as Sideloadly or AltStore, which signs it with your own Apple ID.

The pictures ending in `iPhone.png` and `iPad.png` show the app running in Apple's simulator.
